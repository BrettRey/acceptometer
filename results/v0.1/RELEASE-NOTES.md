# Acceptometer v0.1.0

The first public release of Acceptometer includes the joint Bayesian
measurement-error model, simulation and validation ladder, warrant generation,
local HF/Ollama instruments, and optional Claude Opus 5 and GPT-5.6
Sol/Terra/Luna frontier-judge runners.

The release also publishes a safe aggregate snapshot for the eleven-judge
pilot comparison and a deterministic check for the generated table in
`PILOT-REPORT.md`.

The pilot warrant remains `descriptive_only`. Participant response-style PPCs
failed and the source-item set is contamination-suspect, so these results do
not license a deployment tier. Participant-level ratings, sentence text, raw
model outputs, run directories, and posterior draws are intentionally excluded.
